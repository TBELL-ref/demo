DEFINITION

성능 테스트란?

성능 테스트(Performance Testing)는 시스템의 성능을 측정하고 분석해, 요구사항을 만족하는 데 필요한 처리량과 응답시간, 자원 사용 등의 지표를 산출하고 평가하는 테스트입니다. 운영 중 발생할 수 있는 문제를 미리 파악하고, 시스템의 한계와 임계점을 확인해 안정적인 운영 기반을 마련합니다.

WHEN YOU NEED IT

이럴 때 필요합니다

  1. 01
    서비스 오픈이나 이벤트로 사용자가 몰릴 때
  2. 02
    차세대 전환·인프라 변경을 앞두고 있을 때
  3. 03

  4. 04
    서버 증설 규모의 근거가 필요할 때

FAQ

자주 묻는 질문

성능 테스트와 부하 테스트는 같은 말인가요?

부하 테스트는 성능 테스트의 한 종류입니다. 성능 테스트는 부하, 스트레스, 확장성, 안정성, 볼륨, 구성 테스트를 모두 포함하는 더 넓은 개념입니다.

언제 성능 테스트를 해야 하나요?

서비스 오픈이나 대규모 이벤트처럼 사용자가 몰리기 전, 차세대 시스템 전환이나 인프라 변경 전에 수행하는 것이 좋습니다.

어떤 도구를 사용하나요?

LoadRunner, Apache JMeter 등 대표적인 성능 테스트 도구를 사용하며, 개발 연구소가 대상 시스템과 목적에 맞는 도구 선정부터 테스트까지 함께합니다.

사용자가 몰려도 버티나요?

예상 사용자 수와 대상 시스템을 알려 주시면 성능 목표와 시나리오를 함께 설계해 드립니다.
