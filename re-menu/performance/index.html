성능 테스트
(Performance Testing)

시스템의 성능을 측정하고 분석하는 성능 테스트는 요구사항을 만족시키는 데 필요한 처리량과 응답시간, 자원 사용 등과 같은 성능 측정 지표를
산출하여 시스템의 성능을 평가합니다. 개발된 시스템의 성능 테스트를 통해, 향후 운영 중 발생할 수 있는 문제점을
사전에 파악할 수 있으며 시스템의 한계와 임계점을 검증함으로써 안정적인 운영을 위한 기틀을 마련할 수 있습니다.

업무범위

티벨은 각 분야의 전문가를 활용하여 성능 테스트를 수행하고 있으며,
특히 개발 연구소를 통해 최적의 도구 선정과 테스트에 이르기까지의 과정에 참여하고 있습니다.

  • 부하 테스트
  • 확장성 테스트
  • 스트레스 테스트
  • 안정성 테스트
  • 볼륨 테스트
  • 구성 테스트

주요 활동 도구

  • 로드러너
  • 제이미터 등

자주 묻는 질문

성능 테스트와 부하 테스트는 같은 말인가요?

부하 테스트는 성능 테스트의 한 종류입니다. 성능 테스트는 부하, 스트레스, 확장성, 안정성, 볼륨, 구성 테스트를 모두 포함하는 더 넓은 개념입니다.

언제 성능 테스트를 해야 하나요?

서비스 오픈이나 대규모 이벤트처럼 사용자가 몰리기 전, 차세대 시스템 전환이나 인프라 변경 전에 수행하는 것이 좋습니다.

어떤 도구를 사용하나요?

LoadRunner, Apache JMeter 등 대표적인 성능 테스트 도구를 사용하며, 개발 연구소가 대상 시스템과 목적에 맞는 도구 선정부터 테스트까지 함께합니다.
