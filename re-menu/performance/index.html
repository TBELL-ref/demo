Performance Testing

성능 테스트 · 부하 테스트

성능 테스트(부하 테스트)는 처리량·응답시간·자원 사용량을 측정해 시스템의 한계와 임계점을 검증하는 테스트입니다.

테스트 문의하기자주 묻는 질문
  • QA 아웃소싱
  • 테스트 자동화
  • 블랙박스 테스트
  • 화이트박스 테스트
  • API 테스트
  • 성능 테스트

이럴 때 필요합니다

  1. 01

    서비스 오픈이나 이벤트로 사용자가 몰릴 때

  2. 02

    차세대 전환·인프라 변경을 앞두고 있을 때

  3. 03

    느리다는 사용자 불만이 늘어날 때

  4. 04

    서버 증설 규모의 근거가 필요할 때

목적에 맞는 성능 테스트를 고릅니다

  1. 부하 테스트

    예상 사용자 수에서 응답시간과 처리량

  2. 스트레스 테스트

    한계를 넘을 때 무너지고 회복하는 방식

  3. 확장성 테스트

    자원을 늘린 만큼 성능이 느는지

  4. 안정성 테스트

    오래 운영해도 성능이 유지되는지

  5. 볼륨 테스트

    대량 데이터에서도 빠르고 정확한지

  6. 구성 테스트

    설정과 환경에 따른 성능 차이

주요 도구 LoadRunner · Apache JMeter — 개발 연구소가 도구 선정부터 테스트까지 함께합니다

자주 묻는 질문

사용자가 몰려도 버티나요?

예상 사용자 수와 대상 시스템을 알려 주시면 성능 목표와 시나리오를 함께 설계해 드립니다.

성능 테스트란 무엇인가요?

시스템의 처리량, 응답시간, 자원 사용 등 성능 지표를 측정하고 분석해, 요구사항을 만족하는지와 시스템의 한계·임계점을 검증하는 테스트입니다. 운영 중 발생할 수 있는 문제를 사전에 파악할 수 있습니다.

성능 테스트와 부하 테스트는 같은 말인가요?

부하 테스트는 성능 테스트의 한 종류입니다. 성능 테스트는 부하, 스트레스, 확장성, 안정성, 볼륨, 구성 테스트를 모두 포함하는 더 넓은 개념입니다.

언제 성능 테스트를 해야 하나요?

서비스 오픈이나 대규모 이벤트처럼 사용자가 몰리기 전, 차세대 시스템 전환이나 인프라 변경 전에 수행하는 것이 좋습니다.

어떤 도구를 사용하나요?

LoadRunner, Apache JMeter 등 대표적인 성능 테스트 도구를 사용하며, 대상 시스템과 목적에 맞춰 최적의 도구를 선정합니다.
