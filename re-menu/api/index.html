API 테스트
(Application Programming Interface Testing)

서로 다른 소프트웨어 시스템 사이에 통신과 연동을 위해 API 테스트는 필수적입니다. 특히 다양한 오픈 플랫폼이 등장하고 있고,
많은 기업들이 서로의 서비스를 연동하기 위한 노력을 늦추지 않고 있으므로, API 테스트의 중요도는 날로 부각된다고 할 수 있습니다.

API 테스트는 기능, 안정성, 성능, 보안성 등을 함께 평가합니다.

기본 테스트 절차

자주 묻는 질문

화면(UI) 테스트와 무엇이 다른가요?

UI 테스트는 사용자가 보는 화면을 통해 확인하고, API 테스트는 화면 뒤에서 시스템끼리 주고받는 데이터를 직접 확인합니다. 화면이 완성되기 전에도 서버 로직을 먼저 검증할 수 있습니다.

API 테스트도 자동화할 수 있나요?

API는 입력과 출력이 명확해 자동화에 잘 맞습니다. 테스트 자동화와 함께 구성하면 배포마다 연동을 자동으로 확인할 수 있습니다.

왜 API 테스트가 점점 중요해지나요?

다양한 오픈 플랫폼이 등장하고 많은 기업이 서로의 서비스를 연동하고 있어, 한 곳의 연동 오류가 전체 서비스 장애로 이어질 수 있기 때문입니다.
